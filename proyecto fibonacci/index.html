Fibonacci y Números Primos

Aplicación automatizada para la validación y optimización algorítmica

Estudiante: Iván Iturri

1. Planificación Inicial (Sección 13 del PDF)

¿Qué problema real voy a resolver?

El filtrado y análisis automático de flujos numéricos para optimizar sistemas criptográficos de seguridad.

¿Usará Fibonacci, primos o ambos?

Ambos conceptos matemáticos de manera combinada e interdependiente.

¿Qué datos ingresará el usuario?

Un número entero positivo ($n$) que define el límite de términos a evaluar en la secuencia.

¿Qué resultado debe mostrar la página?

La serie ordenada en pantalla indicando explícitamente qué valores poseen la propiedad de ser primos.

¿Cómo explicaré el algoritmo de forma sencilla?

El sistema calcula el término de Fibonacci y, mediante un bucle secundario, verifica si tiene divisores exactos antes de continuar.

¿Cómo se adaptará a celulares y PC?

Diseño fluido mediante CSS Grid, Flexbox y Media Queries responsivos.

2. Contexto del Problema

El desarrollo consiste en una herramienta interactiva que calcula la sucesión de Fibonacci y discrimina en tiempo real cuáles términos pertenecen al conjunto de los números primos. Esta combinación es vital en la informática moderna para el diseño de claves y seguridad criptográfica.

3. Explicación del Algoritmo

Para cumplir con las restricciones de la rúbrica, el código opera de manera puramente iterativa usando variables algebraicas primitivas ($a$, $b$, $c$). No se utilizan arreglos (arrays) ni vectores, garantizando un consumo mínimo de memoria.

4. Panel de Control Interactiva

Introduzca el número de términos y ejecute el análisis algorítmico matemático.

6. Conclusión

La optimización de código mediante la teoría de números demuestra que la matemática pura ofrece soluciones de ingeniería eficientes. Evitar el almacenamiento dinámico innecesario reduce el impacto en el procesador y permite un entorno de ejecución ágil tanto en ordenadores como en dispositivos móviles.
